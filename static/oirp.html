Institutional research, on demand.

OIRP curates and publishes the data Carleton uses to plan, evaluate, and improve. This concept explores what it could look like to ask questions of that data directly — in plain language — and get cited, source-grounded answers.

Most institutional questions don't need a dashboard. They need an answer with a footnote: "What was first-year retention last year? And where can I read more?" The data is already published — the friction is in finding it.

The assistant on the right is grounded in OIRP-published source documents (NSSE summaries, Annual Reports, Operating Budget Reports). Every numerical claim is traced to its source PDF and page. When a value isn't in the verified store, the assistant declines and points you to the right OIRP source rather than guessing.

Schema is not the same thing as business context. Real institutional questions live in the gap between the two.

How it works

A curated semantic layer documents each KPI Carleton tracks — its definitions, calculation methods, synonyms, comparison groups, and verified values with page-level citations. The assistant queries this layer through structured tools, then composes answers in natural language with explicit confidence tiers (high / medium / low) so reviewers know how much to trust each response.

Today the verified store covers six KPIs across student engagement, retention, and enrolment. The architecture is designed so OIRP's existing Power BI / Data Cubes back-end could plug in without changing the assistant layer above.

Built as a portfolio project to demonstrate how a semantic-layer-grounded agent could fit alongside OIRP's existing reporting tools. View source on GitHub →
